# Excel Data Cleaning and Analysis Using Power Query

## Project Overview

This project focuses on cleaning, transforming, and analyzing data from three Excel files using Microsoft Excel and Power Query.

The goal was to combine raw data from multiple files, improve data quality, calculate the number of days between order dates and payment dates, and analyze the prepared data using PivotTables.

## Tools Used

- Microsoft Excel
- Power Query
- PivotTables

## Project Steps

### 1. Data Integration
- Combined data from three Excel files using Power Query.

### 2. Data Cleaning and Transformation
- Cleaned and transformed the raw data.
- Prepared the data for analysis.
- Applied appropriate data types and transformations where needed.

### 3. Date Analysis
- Calculated the number of days between order dates and payment dates.

### 4. Data Analysis
- Used PivotTables to summarize and analyze the prepared data.

## Key Skills Demonstrated

- Data Cleaning
- Data Transformation
- Data Integration
- Power Query
- Date Calculations
- PivotTable Analysis

## Project Outcome

This project provided practical experience in preparing raw data from multiple files and transforming it into a structured dataset for analysis using Excel.
